# Состав решения Talentro (MVP к 22.11)
**Версия документа:** 1.0  
**Статус:** Утверждено командой

Документ строго фиксирует функциональные рамки продукта до контрольной точки 22 ноября. Все задачи за пределами этого списка не входят в основной скоуп MVP.

---

## 1. Входит в MVP (Делаем к заморозке)
Полное соответствие базовому ТЗ:
1. **Каталог секций и кружков:**
   - Карточки занятий (название, цена, возрастные ограничения, город, категория, описание).
   - Фильтрация по городам/районам, категориям, возрасту и стоимости.
   - Полнотекстовый поиск по ключевым словам.
2. **Личные кабинеты и роли:**
   - Аутентификация и регистрация пользователей.
   - Разделение прав: Пользователь / Владелец организации / Модератор.
   - Кабинет владельца: подача заявки и добавление секций/услуг.
   - Модерация: проверка и публикация анкет модератором.
3. **Платформа и клиенты:**
   - Адаптивный веб-клиент на React/Vite (десктоп + мобильный вид).
   - Мобильное приложение (Android APK).
   - Серверный API на Go (роутинг, работа с PostgreSQL).
4. **Инфраструктура:**
   - Docker и Docker Compose для локального развертывания.
   - Деплой веб-части на Vercel и стендового сервера с HTTPS.

---

## 2. По возможности (Опциональный функционал)
Реализуется при досрочном завершении базового скоупа:
- Быстрый вход через Telegram / Google.
- Уведомления владельцу секции на почту/мессенджер о результате модерации.
- Интерактивная карта с метками «секций рядом со мной».

---

## 3. НЕ делаем в рамках MVP
Функционал исключен из первой версии:
- **Онлайн-платежи и эквайринг:** исключено из-за региональных ограничений ПМР и отсутствия юридического лица.
- **Встроенные чаты реального времени:** для связи используются прямые контакты/телефон организаций.
- **Сложная система онлайн-бронирования мест со списанием слотов:** заявка фиксируется в статусе запроса.
