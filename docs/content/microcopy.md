# Микрокопия Talentro: состояния, по ТЗ §3.1.8 и §3.3

Готовые строки — их можно переносить в код как есть. Проверено на стенде 4 ноября 2026:
витрина `http://26.52.103.163:3000`, API `http://26.52.103.163:8080/api/v1/...`, исходники
`D:\CyberSprint\.worktrees\integration\web\`.

**Лимиты соблюдены и посчитаны** (`len()` в Python, кириллица/пробелы/«ёлочки» = по 1 символу):
заголовок ≤ 28, текст ≤ 140, подпись кнопки ≤ 20. Число стоит в каждой строке в скобках.

## Тон: четыре правила

1. Никаких «осуществляется», «в данный момент», «произойдет загрузка». Говорим, что случилось и что делать.
2. **Не обещать сохранение там, где данных не сохраняют.** Избранное, заявки «не нашли занятие»,
   черновики анкеты и отзыва — только `localStorage` браузера
   (`web/src/components/providers/AppProviders.tsx:172`, `web/src/components/request/RequestClient.tsx:70`,
   `web/src/components/account/ApplicationForm.tsx:434`, `web/src/components/activity/ReviewsBlock.tsx:104`).
   Голоса и отзывы вообще не пишутся никуда, кроме состояния вкладки
   (`web/src/components/activity/ActivityDetail.tsx:190-208`, `ReviewsBlock.tsx:53`).
   Поэтому в текстах ниже прямо назван браузер, а не «ваш аккаунт».
3. Не выдумывать причину. Если мы не знаем, почему данные не пришли, текст говорит
   «не дошли», а не «сервер упал».
4. Одна кнопка — одно действие. Там, где повтор бессмыслен (например, пустое расписание), кнопка
   ведёт к звонку, а не к «обновить».

## Куда это ложится в код

Строки готовы к переносу как константы; трогать логику не нужно, кроме трёх мест, где текст
не может быть честным без маленького изменения:

- п. 8: `verifiedAt` для бейджа должен приходить из `contacts_verified_at`, а не из `updated_at`
  (`web/src/lib/api-server.ts:255`) — зона: веб.
- п. 1: поиск и фильтры — один блок `emptyState` на два состояния (`CatalogClient.tsx:485-511`) — зона: веб.
- п. 15, 16, 17: заголовки toast'ов обещают действие сервера; правка чисто текстовая, но пока сервера
  нет, менять надо и формулировку, и (опционально) сам факт кнопки «Опубликовать» — зона: веб + бэкенд.
