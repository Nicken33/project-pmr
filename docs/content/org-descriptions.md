# Описания организаций

Составлено по `GET /api/v1/organizations/{id}` и связанным занятиям из
`GET /api/v1/activities/{id}`. Использованы только реальные поля: название,
тип, город, адрес, телефон, описание, занятия, возраст, цена и расписание.
Рейтингов, отзывов и счётчиков голосов в API нет — поэтому их нет и здесь.

Общее для всех восьми организаций: поле `contacts_verified_at` пустое, то есть
контакты не подтверждены; `email` и `site` не заполнены ни у одной из них.
Цены указаны без валюты — в API валюта не задана. «За месяц» и «за занятие»
соответствуют полю `price_period` (`month` и `session`).

## Что осталось пустым и почему

- **Рейтинги и отзывы:** в API нет ни полей оценок, ни эндпоинта отзывов;
  добавлять числа было бы выдумкой.
- **Почта и сайт:** у всех восьми организаций `email` и `site` равны `null`.
- **Подтверждение контактов:** `contacts_verified_at` пуст у всех восьми.
- **Возраст и места у репетитора:** в API `age.min`/`age.max`, название группы
  и `seats` не заполнены.
- **Места у отдельных групп:** у группы 7–10 лет СДЮШОР «Днестр», группы
  «Школьники» клуба «Самокиндар» и группы 6–18 лет шахматного клуба поле
  `seats` пустое.
- **Фотографии:** пути есть у семи карточек, но файлы недоступны; у ДМШ
  «Весёлые ноты» путей нет. Подробности — в `photo-inventory.md`.
