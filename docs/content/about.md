# О проекте Talentro

## Что это

Talentro — каталог детских секций, кружков и занятий Приднестровья. Задача
каталога — собрать в одном месте основные сведения о занятии: направление,
возраст, город и адрес, стоимость, телефон и расписание, — чтобы родителю не
приходилось искать их по сайтам учреждений и социальным сетям.

Проект находится на стадии MVP и работает на тестовом стенде. Это не
официальный сайт перечисленных организаций: каталог не действует от их имени
и не заменяет собой приёмную школы, студии или мастера.

## Что уже есть в каталоге

По состоянию на 04.11.2026 API отдаёт:

- 63 категории, включая 9 верхнеуровневых направлений;
- 8 опубликованных занятий от 8 организаций;
- 8 городов в справочнике, при этом занятия сейчас есть в четырёх:
  Тирасполе, Бендерах, Рыбнице и Дубоссарах.

У каждой карточки занятия есть направление, город, телефон, адрес и
координаты. Возраст, цена и расписание заполнены там, где они есть в анкете:
у части занятий в API несколько групп с разным возрастом, ценой и временем,
а у репетитора возраст и название группы не указаны.

## Откуда берутся данные

Карточки занятий и организаций ведутся в базе проекта. В каталог попадают
только записи со статусом «опубликовано»; черновики и записи на модерации
пользователю не показываются.

Описания занятий и организаций в этом пакете составлены по полям, которые
реально отдаёт API: название, тип организации, город, адрес, телефон, возраст,
цена и расписание. Мы не добавляем сведения, которых нет в источнике, — ни
цены, ни адреса, ни возраста, ни имён сотрудников.

## Как проверяются данные

В API есть два разных признака, и их важно не путать:

- **Флаг `verified` у занятия.** Сейчас он выставлен только у одной карточки
  из восьми — детской музыкальной школы «Весёлые ноты». У остальных занятий
  флаг снят.
- **Поле `contacts_verified_at` у организации.** Оно заполняется, когда
  контакты организации подтверждены. Сейчас у всех восьми организаций с
  опубликованными занятиями это поле пустое.

Поэтому телефоны, адреса и расписание в карточках следует воспринимать как
данные из анкеты, а не как подтверждённые звонком. Перед записью на занятие
позвоните организации и уточните актуальность: цена, наличие мест и время
могут измениться.

Пустое поле в карточке означает, что данных нет. Мы не подставляем
правдоподобные догадки вместо возраста, цены или адреса.

## Чего пока нет

Чтобы не создавать ложных ожиданий, перечислим функции, которых на стенде
нет:

- **Нет рейтингов и отзывов.** В API отсутствуют оценки, счётчики голосов и
  отзывы; страница отзывов не получает данных из API. Любые звёзды и числа
  голосов, если они где-то видны, не являются данными каталога.
- **Нет фотографий в выдаче.** Пути к фотографиям прописаны у семи занятий из
  восьми, но файлы по этим путям сейчас недоступны; у музыкальной школы
  «Весёлые ноты» фотографий в API нет вовсе. Вместо фото показывается
  заглушка.
- **Нет онлайн-записи и оплаты.** Каталог не принимает платежи и не бронирует
  места. Все договорённости — напрямую с организацией.
- **Нет полноценных аккаунтов.** В API есть только служебный тестовый вход;
  регистрация по почте и паролю, личный кабинет, избранное и модерация на
  сервере ещё не реализованы.
- **Нет серверного приёма заявок и жалоб.** Формы на витрине могут сохранять
  данные только в браузере пользователя; в API нет эндпоинтов для заявок,
  отзывов и обращений.
- **Нет подтверждённых публичных контактов проекта.** Поэтому мы не указываем
  почту или телефон-заглушку: неподтверждённый контакт выглядел бы как
  настоящий.

## Правила каталога

1. В каталог попадают только опубликованные записи.
2. Одно занятие — одна карточка; разные адреса одной организации считаются
   точками проведения, а не отдельными занятиями.
3. Цена указывается только в том виде, в каком она есть в анкете: сумма и
   период. Формулировки «договорная» и «уточнять на месте» не добавляются.
4. Возраст указывается диапазоном в годах. Если в API возраст не заполнен
   (например, у репетитора по математике), в карточке его нет.
5. Расписание показывается по группам. Если расписания нет, оно не
   выдумывается.
6. Названия, адреса и телефоны не редактируются «для красоты»: они приводятся
   так, как указаны в источнике.
7. Категории и их описания — редакционные: они объясняют, что это за
   направление, и не являются заявлением конкретной организации.

## Ограничения стенда

Стенд предназначен для проверки гипотез и приёмки MVP. Данные в нём
демонстрационные и могут быть неполными; состав карточек, цены и расписание
могут измениться без предупреждения. Стенд не является публичным
продакшеном, и на него не стоит опираться как на юридически значимый источник
информации об организациях.

Если вы заметили расхождение, ориентируйтесь на данные самой организации:
позвоните по указанному телефону и сверьте цену, возраст и время занятия.
