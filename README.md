# Project PMR

Единая платформа проекта (Web, Mobile и Backend API).

## О проекте
Репозиторий объединяет серверную часть, веб-клиент, мобильное приложение и инфраструктуру базы данных PostgreSQL с быстрым развертыванием через Docker Compose.

## Структура репозитория
- `backend/` — серверная часть и API
- `frontend/web/` — веб-интерфейс
- `frontend/mobile/` — мобильное приложение
- `database/` — SQL-скрипты инициализации схемы и начальных данных (`init.sql`)
- `docs/` — документация, инструкции и регламенты команды
- `docker-compose.yml` — конфигурация контейнеров (БД, API, Web)

## Быстрый запуск
1. Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.example .env
   ```
2. Запустите инфраструктуру через Docker:
   ```bash
   docker compose up -d
   ```

## Локальные утилиты
- **Консольный фильтр занятий (Go CLI):**
  В каталоге `backend/` находится утилита для интерактивного поиска и фильтрации секций по тестовым данным (`activities.json`):
  ```bash
  cd backend
  go run main.go
  ```
